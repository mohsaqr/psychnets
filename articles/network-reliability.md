# Edge-weight stability and split-half reliability

A psychological network is estimated from one sample, and another sample
from the same population would give a somewhat different network. Before
an edge is interpreted or a node is called the most central, the analyst
needs to know whether the result would reappear: whether an edge differs
reliably from zero, whether two nodes can be ranked, and whether the
structure survives when part of the sample is removed or when the sample
is split in two. Resampling answers these questions without
distributional assumptions, by re-estimating the network many times on
samples drawn from the data (Epskamp et al., 2018).

This article applies five such diagnostics to one network: bootstrap
confidence intervals for edges and centralities, bootstrap tests of
differences between nodes, the stability of centrality and of edge
weights when cases are dropped, and the agreement of networks estimated
on two halves of the sample. Each diagnostic refits the network with the
same estimator, so the same steps apply to any estimator.

``` r

library(psychnets)
set.seed(1)
```

The diagnostics resample at random, so the seed is set once to make the
results reproducible.

## Data

`SRL_Claude` holds 300 sets of responses to the Motivated Strategies for
Learning Questionnaire generated by a large language model (Claude) in a
study of how such models answer psychological surveys (Saqr, 2025). Its
responses are more internally consistent than human responses, which
yields a network with large edges; it serves here as an example and is
not evidence about students.

- **Nodes:** five construct scores on a scale from 1 to 7: `CSU`
  (cognitive strategy use), `IV` (intrinsic value), `SE`
  (self-efficacy), `SR` (self-regulation) and `TA` (test anxiety).
- **Observations:** one row per respondent; the data are complete.

## How precise is each edge?

[`net_boot()`](https://pak.dynasite.org/psychnets/reference/net_boot.md)
draws bootstrap samples of the respondents with replacement,
re-estimates the network on each, and summarizes the distribution of
every edge weight: its mean, its 95% percentile interval, and the
proportion of samples in which the edge was selected. An edge is flagged
`significant` when its interval excludes zero. An applied analysis uses
at least 1,000 samples; 200 keep this example short.

``` r

b <- net_boot(SRL_Claude, method = "glasso", n_boot = 200, cores = 1)
b
#> <psychnet_bootstrap> glasso, 200 resamples, 95% CI
```

Eight of the ten edges have intervals that exclude zero and are selected

0.12, and is selected in only 55% of the samples; `IV`–`TA` (-0.014,

their sign can be interpreted at this sample size. The plot shows each
edge with its interval, ordered by size:

Self-regulation has the largest strength, 1.95 with an interval from

## Which nodes can be ranked?

[`difference_test()`](https://pak.dynasite.org/psychnets/reference/difference_test.md)
tests whether two nodes differ in centrality, or two edges in weight,
within the network. For each pair it takes the difference in every
bootstrap sample, forms its percentile interval and a two-sided
bootstrap p-value, and flags the pair when the interval excludes zero.
It reads the samples already stored by
[`net_boot()`](https://pak.dynasite.org/psychnets/reference/net_boot.md),
so nothing is refitted. With ten pairs, `p_adjust = "BH"` controls the
false discovery rate (Benjamini & Hochberg, 1995).

``` r

difference_test(b, type = "strength", p_adjust = "BH")
#>    item1 item2    value1    value2    obs_diff        lower       upper
#> 1    CSU    IV 1.4794795 0.9920086  0.48747089  0.241546367  0.66372411
#> 2    CSU    SE 1.4794795 1.2652845  0.21419501  0.038286544  0.42634973
```

Nine of the ten pairs differ. Self-regulation is stronger than every
other node (all adjusted p \< 0.01), and cognitive strategy use is
stronger than self-efficacy and test anxiety (adjusted p = 0.044 for
both). The one pair that cannot be ordered is self-efficacy and test
anxiety: their difference is -0.12, with an interval from -0.33 to 0.08
and p = 0.26. A report can rank self-regulation first and intrinsic
value last, but should not order self-efficacy and test anxiety.

## Is the centrality ranking stable when cases are dropped?

[`net_stability()`](https://pak.dynasite.org/psychnets/reference/net_stability.md)
re-estimates the network on random subsets that drop an increasing
proportion of the respondents and correlates the centralities of each
subset with those of the full sample. The correlation-stability
coefficient (CS-coefficient) is the largest proportion of cases that can
be dropped while the correlation stays at or above 0.7 in at least 95%
of the subsets (Epskamp et al., 2018).

``` r

st <- net_stability(SRL_Claude, method = "glasso", iter = 100)
st
#> <psychnet_stability> glasso, 100 subsets/proportion
#>   CS-coefficient (pearson cor > 0.70 in > 95% of subsets):
#>     strength             0.70
#>     expected_influence   0.90
```

The CS-coefficient is 0.70 for strength and 0.90 for expected influence.
Up to 70% of the respondents can be dropped and the strength values of
the subsets still correlate at least 0.7 with those of the full sample
in 95% of the subsets. Epskamp et al. (2018) suggest a CS-coefficient of
at least 0.25, and preferably 0.5, before centrality is interpreted;
both measures exceed it, so the centrality order of this network can be
reported. The plot shows the mean correlation at each drop proportion
with a band of one standard deviation and the 0.7 threshold:

``` r

plot(st)
```

![](network-reliability_files/figure-html/stability-plot-1.png)

## Is the edge structure stable when cases are dropped?

applies the same case-dropping design to the edges. At each drop
proportion it compares the edge weights of each subset with those of the
full sample through their correlation and through the mean, median and
largest absolute difference. The edge-weight CS-coefficient is defined
as for centrality.

## Does the network replicate across halves of the sample?

[`net_split_reliability()`](https://pak.dynasite.org/psychnets/reference/net_split_reliability.md)
divides the sample at random into two halves, estimates a network on
each, and compares the two sets of edges, repeating the split many
times. The result has one row per comparison measure, with its mean,
standard deviation and the 2.5% and 97.5% quantiles across splits.

``` r

rel <- net_split_reliability(SRL_Claude, method = "glasso", iter = 100)
rel
#> # split-half reliability: glasso | 100 iterations (50/50 split)
#>           metric       mean         sd      lower     upper n_valid
#> 1   mean_abs_dev 0.06406132 0.02201012 0.03319670 0.1092927     100
#> 2 median_abs_dev 0.05674286 0.02297601 0.02204948 0.1086049     100
#> 3    correlation 0.98243129 0.01208858 0.95313106 0.9960735     100
#> 4    max_abs_dev 0.14177087 0.05219793 0.06749545 0.2635560     100
```

Across 100 splits, the edges of the two halves correlate 0.982 on
average, with 95% of the splits between 0.953 and 0.996. Two independent
samples of 150 respondents thus recover nearly the same edge structure.
The mean absolute difference between the halves is 0.064, and the
largest single-edge difference averages 0.142: a typical edge moves by
less than 0.1 between halves, while the least stable edge can move by
about 0.14.

``` r

plot(rel)
```

![](network-reliability_files/figure-html/reliability-plot-1.png)

## When to use which diagnostic

| Question | Verb | Read the result with |
|----|----|----|
| How precise is each edge and centrality? | [`net_boot()`](https://pak.dynasite.org/psychnets/reference/net_boot.md) | `as.data.frame(b)`, `as.data.frame(b, what = "centrality")`, [`plot()`](https://rdrr.io/r/graphics/plot.default.html) |
| Do two edges or two nodes differ? | [`difference_test()`](https://pak.dynasite.org/psychnets/reference/difference_test.md) | the returned table, [`plot()`](https://rdrr.io/r/graphics/plot.default.html) |
| Is the centrality order stable when cases are dropped? | [`net_stability()`](https://pak.dynasite.org/psychnets/reference/net_stability.md) | `as.data.frame(st, what = "cs")`, `as.data.frame(st)`, [`plot()`](https://rdrr.io/r/graphics/plot.default.html) |
| Is the edge structure stable when cases are dropped? | [`net_casedrop_reliability()`](https://pak.dynasite.org/psychnets/reference/net_casedrop_reliability.md) | the returned table, [`plot()`](https://rdrr.io/r/graphics/plot.default.html) |
| Does the network replicate across halves? | [`net_split_reliability()`](https://pak.dynasite.org/psychnets/reference/net_split_reliability.md) | the returned table, [`plot()`](https://rdrr.io/r/graphics/plot.default.html) |

- Report bootstrap intervals with every edge that is interpreted, and do
  not interpret edges whose interval includes zero.
- Rank nodes only after the difference test and the CS-coefficient
  support the ranking; a CS-coefficient below 0.25 means that centrality
  should not be interpreted.
- Case-dropping and split-half reliability describe the whole structure;
  bootstrap intervals describe individual edges. A network can be stable
  as a whole while some of its edges are not, as in this example.
- All diagnostics assume that the respondents are independent. Repeated
  measures of the same persons need a resampling scheme that keeps each
  person’s observations together.
