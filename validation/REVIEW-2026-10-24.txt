CONFIRMED FINDINGS (ordered by impact)

1. [P1] Undefined sparse-draw correlations are removed from the CS probability denominator, inflating stability.
Locations: R/reliability.R:168 and R/stability.R:99,111.
The CS coefficient promises a threshold correlation with probability >= certainty across case-dropped subsets. Empty estimated networks produce undefined correlations, but colMeans(..., na.rm=TRUE) excludes those subsets instead of treating their failure to attain a defined threshold as unsuccessful. These are often valid, successfully estimated sparse models, so n_failed remains zero and no warning exposes the excluded subset count.
Exact reproduction:
set.seed(1)
x <- rnorm(100)
d <- data.frame(x=x, y=.8*x+rnorm(100,sd=.6), z=rnorm(100))
set.seed(3)
cd <- net_casedrop_reliability(d, drop_prop=.9, iter=40)
m <- attr(cd,'correlations')
Result: CS=.9, n_success=40, seven NA correlations; reported conditional passing probability mean(m>=.7,na.rm=TRUE)=1. Only 33/40=.825 subsets attain .7, below the default .95 certainty. Expected: count undefined correlations as failures for the probability, or mark/refuse the unavailable diagnostic explicitly; do not claim 95% stability.
The same input and resampling seed also reproduce the error in net_stability(d,drop_prop=.9,iter=40): both strength and expected_influence have CS=.9 and prop_above=1 despite n_success=40 and the same seven empty draws.
Script: /private/tmp/framework-review-cs-sweep.R (first seed reproduces), /private/tmp/framework-review-cs.R.

2. [P1] Custom labels plus ignored nonnumeric columns silently erase resampling networks.
Location: R/reliability.R:30-42 (.psn_refit_network).
The function renames raw input columns only if the label count matches ncol(raw data). With an ignored id/factor column, label count correctly matches the modeled numeric nodes, but not the raw input columns. The estimator receives original column names and no labels argument, then intersect(old, labels) is empty and all weights become zero. This shared helper powers bootstrap, stability, and both reliability diagnostics.
Reproduction:
set.seed(11)
x <- data.frame(a=rnorm(30),b=rnorm(30)); x$c <- x$a+rnorm(30,0,.2)
d <- data.frame(id=letters[1:30],x)
a <- net_boot(d, method='pcor', n_boot=3, cores=1)
b <- net_boot(d, method='pcor', n_boot=3, cores=1, labels=c('A','B','C'))
Without labels observed a-c weight is .962472661; with labels every observed weight and every bootstrap draw is zero. Expected: same estimates with renamed nodes. Direct estimator labels correctly support the node count.
Script: /private/tmp/framework-review-repro.R.

3. [P2] Standardized event-group resampling loses the effective sample size and can change the observed network.
Location: R/groups.R:73 (subsets stores only design matrix, dropping des$n); reconstruction at R/groups.R:205-207. Related generation: R/multilevel.R:233.
For repeated-person/event data with standardize=TRUE, the original fit uses n_within=N-J. The grouped container labels centered rows as ordinary cross-sectional data and discards that effective n; resampling verbs reconstruct observed fits with N rows instead. This changes significance tests and EBIC selection even before resampling.
Exact reproduction:
set.seed(1)
d <- data.frame(id=rep(1:40,each=3), group=rep(c('A','B'),each=60), x=rnorm(120), y=rnorm(120), z=rnorm(120))
d$y <- .4*d$x+d$y
f <- psychnet(d,id='id',group='group',method='pcor',alpha=.05)
b <- net_boot(f,n_boot=2,cores=1)
f$A has n=40 and one edge; b$A$observed has n=60 and three edges; max absolute weight discrepancy is .2839472. Expected: observed reconstruction reproduces f$A, with effective sample size preserved or unsupported grouped resampling rejected clearly. The issue also reaches net_compare() reconstruction.
Scripts: /private/tmp/framework-review-event-n.R, /private/tmp/framework-review-event.R.

4. [P2] One NA in an event feature drops the whole variable despite requested pairwise handling.
Location: R/multilevel.R:153-159 (.fit_ggm).
The precheck apply(mat,2,sd) does not use na.rm, so any missing value makes its SD NA. That variable is then reported as zero-variance and removed before .cor_input can apply pairwise/listwise handling. A repeated-person feature also propagates the NA through rowsum into other centered observations.
Exact reproduction (single occasion avoids the latter complication):
set.seed(22)
d <- data.frame(id=seq_len(120),x=rnorm(120),y=rnorm(120),z=rnorm(120)); d$y[1] <- NA
f <- psychnet(d,id='id',vars=x:z,method='pcor',na_method='pairwise')
Returned nodes are x,z and warning says y has zero variance. Ordinary pcor_network(d[c('x','y','z')],na_method='pairwise') keeps all three nodes. Expected: missing-data handling applies to observations, not automatic deletion of an otherwise varying variable.
Script: /private/tmp/framework-review-event-more.R (its data has the same valid construction with additional unused g column).

5. [P2] Different multi-column group tuples collide and are silently pooled.
Location: R/groups.R:40-42 (.psychnet_grouped).
Converting interaction(...,sep='-') to character makes tuples ('a-b','c') and ('a','b-c') indistinguishable. The following row selection uses these ambiguous strings to pool cases into the same network.
Reproduction:
set.seed(16)
d <- data.frame(g1=rep(c('a-b','a','other'),each=20),g2=rep(c('c','b-c','z'),each=20),matrix(rnorm(180),60,3))
g <- psychnet(d,group=c('g1','g2'),method='pcor')
Expected three groups of 20 rows. Actual two groups, names a-b-c and other-z, with 40 and 20 rows. Use collision-free tuple/group identities and separately unique display labels. Related interaction-based composite actor/id keys in R/multilevel.R may need the same treatment.
Script: /private/tmp/framework-review-repro2.R.

6. [P2] Two-variable undirected networks crash both edge reliability diagnostics.
Location: R/reliability.R:19-22 (.psn_edge_metrics).
A two-node undirected network has one edge. sd(edge_vector) is NA, so cor_ok is NA and if(cor_ok) throws 'missing value where TRUE/FALSE needed'.
Reproduction: set.seed(11); d <- data.frame(a=rnorm(30),b=rnorm(30)); net_split_reliability(d,method='pcor',iter=2); net_casedrop_reliability(d,method='pcor',iter=2,drop_prop=.2). Both error. The estimators support two variables. Expected: return the available deviation metrics with correlation NA (or reject this diagnostic up front with a clear supported-size requirement).
Script: /private/tmp/framework-review-repro.R.

7. [P2] Grouped resampling silently ignores explicitly supplied estimator dots.
Locations: R/bootstrap.R:147-154; analogous branches R/stability.R:48-54, R/reliability.R:113-118,282-286.
The early grouped branch forwards diagnostic options and estimator_args, but omits list(...). Thus documented estimator options such as cor_method, rule or na_method have no effect in group mode. estimator_args provides a workaround, but is documented as needed for names consumed by the diagnostic, not a prerequisite for all overrides.
Reproduction in /private/tmp/framework-review-repro2.R:
A grouped correlation fit, followed by net_boot(g,n_boot=3,cores=1,cor_method='spearman'), yields Pearson observed xy=.9105406. Direct net_boot(attr(g,'subsets')$A,method='cor',n_boot=3,cores=1,cor_method='spearman') yields .9652948. Expected the explicitly requested estimator option to be forwarded (and override stored defaults) consistently.

8. [P2] Valid groups of within/between models cannot be printed or summarized.
Locations: R/groups.R:114-116 and140-143.
psychnet(data,id='id',group='g',standardize=FALSE) legitimately returns a psychnet_group with psychnet_multilevel elements. print.psychnet_group/summary.psychnet_group assume each element has $nodes/$edges and vapply(...,integer(1)) fails because nrow(NULL) has length zero. This affects automatic console printing of a valid estimation result.
Reproduction:

d <- data.frame(id=rep(1:40,each=3),g=rep(c('A','B'),each=60),x=rnorm(120),y=rnorm(120),z=rnorm(120))
g <- psychnet(d,id='id',group='g',standardize=FALSE,method='pcor')
print(g); summary(g)
Both throw 'values must be length 1, but FUN(X[[1]]) result is length 0'. Expected nested-level summaries or an intentional, clear supported-operation error; current generic group methods claim to support the returned class.
Script: /private/tmp/framework-review-event-more.R.

CONFIRMED FINDINGS (prioritized)

1. [P2] Missing long-data identifiers fabricate a person by combining unrelated people across waves.
Location: R/panelgvar.R:516-519 (.pgv_wide).
Trigger: NA in the person ID column, with at most one NA record in each wave.
Actual: unique(data[[id]]) retains NA; match(ids, sub[[id]]) matches it across waves as if it were one identified person. This creates a complete artificial panel row from different people's measurements. Other incomplete real persons are dropped, but the artificial person enters the covariance and likelihood.
Expected: reject missing person identifiers as unusable input, or explicitly drop these records before constructing persons; never match unknown identities across waves.
Public reproduction:
  devtools::load_all('.', quiet=TRUE)
  source('tests/testthat/helper-panelgvar.R')
  x <- panel_sim(n=100)
  bad <- c(1,102,203,304)  # four different people, one in each wave
  x$id[bad] <- NA
  wd <- .pgv_wide(x,c('V1','V2','V3'),'id','wave')
  fake <- which(is.na(unique(x$id)))
  complete.cases(wd$wide)[fake]  # TRUE
  identical(unname(wd$wide[fake,]), unname(as.vector(t(as.matrix(x[bad,c('V1','V2','V3')]))))) # TRUE
  f <- suppressWarnings(panel_gvar(x,c('V1','V2','V3'),'id','wave'))
  attr(f,'n') # 97; only 96 identifiable real people are complete.

3. [P2] CFI is NaN for well-fitting panels when both estimated noncentralities are zero.
Location: R/panelgvar.R:577 (.pgv_fit_indices).
Trigger: max(chisq-df,0)=0 and max(baseline_chisq-baseline_df,chisq-df,0)=0. This includes good-fit null panels and perfect-fit data.
Actual: CFI computes 1-0/0 and returns NaN, including in the fit table and printed report.
Expected: handle the zero denominator; the installed primary reference implementations psychonetrics::addfit and lavaan::lav_fit_cfi return CFI=1 in this case.
Exact orthogonal public reproduction above gives chisq=-2.842171e-14, baseline_chisq=0, df=baseline_df=38, CFI=NaN, RMSEA=0. The tiny negative chi-square is floating-point noise, not a convergence failure.

4. [P2] Space-containing node labels can give the wrong significance line type to edges.
Location: R/panelgvar.R:1328-1329 (.pgv_edge_significance).
Trigger: distinct endpoint pairs whose labels concatenate to the same string with a single space.
Actual: paste(from,to) collapses (a b,c) and (a,b c) to 'a b c'; match returns the first edge's significance for both. A significant effect can therefore be drawn dashed or a non-significant one solid, and plot significance counts can be wrong.
Expected: match two-column endpoint identities or integer node-index pairs without ambiguous concatenation.
Public fit reproduction:

  n <- .pgv_plot_temporal(f$temporal)
  s <- .pgv_edge_significance(n,'temporal',e)

ROOT REVIEW: GRAPH METRICS, AGGREGATION, CENTRALITY, PREDICTION, OBJECTS, PLOTS

R1 [P2] Small-world null rewiring retains arbitrary edge orientations and is label dependent.
Location: R/graph_metrics.R:115-122 (.psn_rewire).
The edge list starts with upper-triangle orientations. Every swap preserves the number of occurrences of each vertex in the first versus second edge-list column; neither edge is randomly flipped before rewiring. This is a stricter invariant than undirected degree. A six-cycle reordered c(1,3,5,2,4,6) has edges oriented from one three-node set to the other, and all sampled graphs remain bipartite, even though two disconnected triangles have the same undirected degree sequence and belong in the null.
Confirmed reproduction: create six-cycle A; with set.seed(1), replicate(100, .psn_transitivity(.psn_rewire(A,60L))) has mean .14; the relabelled identical graph has mean exactly 0, with triangles excluded by the invariant. Public net_smallworld consequently uses the wrong reference distribution. For two triangles, permutations of the same adjacency gave smallworldness 5.2 versus 7.381818 with n_rand=200, seed=1. The invariant, not a demand for identical Monte Carlo output under a seed, establishes the defect.
Expected: sample degree-preserving undirected graphs without preserving arbitrary orientation counts; randomly orient the selected edges (or sample both valid pairings) before swaps.
Evidence: /private/tmp/psychnets-root-review.R and /private/tmp/psychnets-root-rewire.R.

R2 [P2] Prediction fails to apply training category encodings to numeric binary MGM nodes.
Location: R/predictability.R:70-74 and 95-100; training encoding is R/mgm.R:80-94.
mgm_fit coerces all categorical variables to factor level indices 0/1. net_predict converts only factor/character columns; numeric categories coded 1/2, -1/1, etc. pass through unchanged. Both predictors and targets are wrong, and the majority baseline can exceed 1, making normalized accuracy fall back to zero.
Repro: set.seed(9); a<-rbinom(300,1,.5); b<-ifelse(runif(300)<.9,a,1-a); d<-data.frame(a=a+1,b=b+1,c=rnorm(300)); f<-mgm_fit(d,types=c('c','c','g'),threshold='none',nlambda=20).
Actual: f$nodes$predictability for a,b is .8133333/.8082192, but net_predict(f,d) gives nCC 0/0 and accuracy .5/.5133333. Recode only the two binary columns to 0/1 before the call and the correct accuracy .9066667/.9066667 and nCC are recovered. Both native=TRUE and native=FALSE are affected.
Expected: preserve the training level mapping and use it for all categorical storage types during prediction. Do not infer a new mapping from the evaluation sample alone.
Evidence: /private/tmp/psychnets-root-categorical.R.

R3 [P2] Display labels replace source-column identity in nodewise prediction.
Location: R/predictability.R:66-69 and 81-86; R/result.R:65 currently stores node name equal to display label.
Repro: set.seed(1); d<-data.frame(a=rbinom(200,1,.5),b=rbinom(200,1,.5),c=rbinom(200,1,.5)); f<-ising_fit(d,labels=c('A','B','C'),nlambda=10); net_predict(f,d).

Expected: maintain source column names separately from labels and select prediction data by source identity, while reporting labels in output.
Evidence: /private/tmp/psychnets-root-predict.R.
This is related to, but independent of, the silent empty-network defect in shared resampling alignment reported by the framework reviewer.

R4 [P3] Signed NCT strength plots label expected influence as global strength.
Location: R/plot.R:436-438.
When net_compare(..., abs=FALSE), the statistic is the difference in signed edge sums, described correctly by summary.psychnet_nct as global expected influence. plot.psychnet_nct(type='strength') unconditionally labels its x axis 'global strength difference (S)', which conventionally means absolute edge sums.
Expected: select the axis label from x$params$abs, matching summary/print. This is a label/interpretation defect, not a numerical permutation-test defect.
